# .github

Plantillas por defecto para los repositorios de [@lautalom](https://github.com/lautalom).

- `pull_request_template.md`: Summary / Evidence / Merge Danger.
- `ISSUE_TEMPLATE/`: bug, mejora y tarea o investigación.

GitHub usa estos archivos en cualquier repo de la cuenta que no tenga los suyos.
Un repo con su propio `pull_request_template.md` o su propia carpeta
`.github/ISSUE_TEMPLATE/` los reemplaza por completo.
